# 探究电流与电压的关系

- 项目 ID：`current-voltage`。受众：初中物理。控制定值电阻不变，用滑动变阻器改变其两端电压，对比电流、I–U 图及 U/I。

六件器材遵循共用库约定，均保留可编辑 Blender 文件、GLB、缩略图与台面坐标锚点。台面用独立摆放区域；导线画在实际接线柱之间。开关、滑片和表针是可独立运动的节点。

1. 顺序拖放或点选六件器材；错序、区域外放置和取消不推进。
2. 断开时连接七根导线并检查。参考接法：电源 + → 开关 → 电流表 + 至 − → 电阻右至左 → 变阻器 A 至 C → 电源 −；电压表 + 接电阻右，− 接左。也允许等电位接法、合法的串联顺序和另外一侧的下接线柱。短路、断路、旁路、反接或变阻器接线不当均不能通电。可撤销上根导线。
3. 沿滑杆拖动滑片或使用滑片控件，使滑片离已接下接线柱最远，接入阻值达 50 Ω，再闭合开关。
4. 读表并记录三组彼此相差至少 0.2 V 的 U、I。参考点 1.00 V/0.10 A、2.00 V/0.20 A、3.00 V/0.30 A；使用 A 端时的滑片位置分别为 100%、40%、20%。采用理想电路，忽略内阻，表格比值按内部计算值显示。
5. 断开开关，两表归零，图和表保留。对比 U/I 和图中数据点：电阻一定时，电流与电阻两端的电压成正比。
6. 重做实验：保留仪器位置，清除导线和记录，回到接线。重新组装：清空器材、导线和记录，恢复初始视角。
