# 高锰酸钾制氧 · 器材入库

项目入口为根目录的制氧实验（平台 ID：oxygen-lab）。本轮登记 16 种器材与操作道具；铁架台保留原 v1 并新增 v2，其余为 v1。目录索引见 [assets/catalog.json](../assets/catalog.json)。

| --- | --- |

| 按用户提供的外形参考独立制作 | 酒精灯（含玻璃瓶、透明液面、棉灯芯和可拆灯帽） |

每项均保留可编辑 Blender 源文件、GLB、PNG、米制锚点及来源说明。目录中的水槽和集气瓶为空器材，水面与气泡由网页呈现。高锰酸钾是药品；实验用品列表中尚未在台面出现的升降台、药匙等不在本次提取范围内。

酒精灯网页预览调整了圆肩厚底玻璃、单独的液面、弯曲棉芯、白瓷灯帽和蓝底黄焰。参考图仅用于核对形状，没有嵌入模型或预览。页面仍沿用现有制氧操作；Blender 候选资产供后续复用评审。

本轮验证：酒精灯源文件用 Blender 5.3 重开核对；实验台通过 1240 px 桌面与 360 px 触屏的装配、点灯、排水集气、移出导管与盖帽检查。按本轮反馈，圆环归入铁架台 v2 的夹具，试管 v1 保持独立。桌面实测从仪器库拖放铁架台和试管：空架夹爪张开，试管吸附后合拢，重置后再打开。模型和网页交付本地审看，评审尚未确认，未登记新公开项目或启动部署。
